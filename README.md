## KI-/Security-Infrastruktur

Ich betreibe eine stark automatisierte KI-/Security-Plattform auf eigenem, gehärtetem Server —
entworfen für **überprüfbare, belastbare Ergebnisse statt Black-Box-Automatik**:

| Baustein | Was es ist |
|---|---|
| **Agenten-Orchestrierung** | ein orchestrierter Verbund aus **40+ spezialisierten Agenten** (Recon, Web-AppSec, Business-Logic, Exploit-Chaining, Validierung …), geführt von einem Overseer in einem Decompose-Assign-Execute-Harden-Loop |
| **Fach-Professoren** | **3 Experten-Rollen** (Protokoll-/RFC-Korrektheit, Mathematik/Krypto, Computer-Vision-Modelle) im adversarialen Review-Loop |
| **MCP-Server** | **20+ eigene/angebundene MCP-Server** als Werkzeug-Schnittstellen (Code-Graph, Semgrep, Filesystem, Repomix, Browser-Steuerung u. a.) |
| **Skills & Commands** | **~100 modulare Skills** + Slash-Commands als wiederverwendbare Verfahren |
| **Self-Learning Memory** | ein selbst-lernendes Markdown+git-Gedächtnis mit semantischem Abruf (HybridRAG), Lern-Schleife und Verdichtung |
| **Pipelines** | reproduzierbare Workflows (pipeline/parallel-Fan-out) mit Härtungs-Gates vor jedem Ergebnis |

**Modell-Disziplin:** schweres Denken, Bauen und Suchen laufen auf passend gewählten Modellen;
jedes Ergebnis wird vor „fertig" adversarial gegengeprüft und live verifiziert.

## Schnittstellen & Stack

```
KI-Systeme    Agent-Orchestrierung · MCP-Server · lokale LLMs (Ollama) · Self-Learning Memory · RAG · Pipelines
Security      Web-AppSec (IDOR/BOLA, Auth, Info-Disclosure) · Recon-Automation · Caido/Burp · Nuclei
Engineering   Python · TypeScript/React · Three.js/WebGL · Swift/SwiftUI · Kotlin
Infrastruktur Linux (gehärtet) · Docker · Bash · git · Cloudflare · Tailscale (privates Mesh)
Privacy       On-Device-Inferenz (ONNX-Runtime-Web / WebGPU) · Redaktion im Browser, kein Upload
```
